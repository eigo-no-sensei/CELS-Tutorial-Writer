**Component ID:** `rust_fixture_tooling`  
**Status:** `active_c4`

## Role

- Compare private source/archive evidence with derived parser, semantic, reconciliation and offline POST states through C4.

## Scope

- Run semantic field parity across private fixtures.
- Require every private edit form to pass C1 validation.
- Require every private fixture pair to construct a valid C2 Revision state with matching explicit source identity.
- Run the two private reconciliation fixtures through Rust summary parsing and C3 reconciliation.
- Prove collision candidates remain group-owned, identical-state resolution is shared-state only, and divergent-state revision-by-ID is blocked.
- Run all 14 private edit fixtures through archive + validated edit -> Revision semantic state -> POST payload.
- Build an independent expected successful-control payload from validated source evidence plus governed archive absent authority and require exact map equality.
- Count Final Reading coverage and historical absent discrepancies as governed C4 evidence.
- Inspect summary/edit/print/revision fixtures.
- Adapt captured expected-fixture JSON into semantic archive records for offline revision diagnostics.

## Authority

- Diagnostic evidence only; it does not mutate canonical contracts automatically.

## Failure semantics

- Strict gate requires exact approved parity baseline and allowlisted mismatch identities; unexpected mismatch/unavailable is failure.
- Any private fixture that cannot pass C1 validation or C2 Revision construction is a strict failure.
- Missing or unexpected C3 collision fixtures, positional collision assignment, or successful divergent revision resolution is a strict failure.
- Any C4 fixture payload key/value difference, source timestamp identity mismatch, missing Final Reading field, wrong archive-authoritative absent encoding, or unexpected discrepancy count is a strict failure.
