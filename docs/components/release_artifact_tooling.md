# Release artifact and acceptance tooling — active component spec

> Generated from `contracts/component_boundaries.json`. Do not edit this file directly.

**Component ID:** `release_artifact_tooling`  
**Status:** `active_gri`

## Role

- Run governed release checks, bind strict evidence to exact source/dependency/toolchain identity, package accepted source without rebuilding, and verify final archive bytes.

## Scope

- Execute portable/strict scopes from release_gate.json with explicit evidence classes and SKIP semantics.
- Record strict evidence outside source with source fingerprint, lock-set hash and toolchain identity.
- Fail closed unless accepted strict evidence matches current source fingerprint before packaging.
- Stage governed files, create exact file checksum/release manifests, archive without rebuild, and verify ZIP bytes/receipt.

## Authority

- Sole writer of repository-governed release acceptance/distribution evidence state.
- Strict evidence is evidence, not self-promoting runtime authority; packaging cannot change source, dependencies or build outputs after acceptance.

## State transitions

- working source -> checks -> strict accepted evidence -> identity revalidation -> staged immutable package -> checksum/ZIP verification -> release artifact receipt.

## Failure semantics

- Any FAIL/SKIP in strict mode prevents strict acceptance.
- Source/lock mismatch after acceptance aborts packaging.
- Archive/checksum mismatch aborts RELEASE_ARTIFACT_VERIFIED and never triggers rebuild.
