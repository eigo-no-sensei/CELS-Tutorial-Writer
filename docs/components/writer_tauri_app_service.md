# Tutorial Writer Tauri application service — active component spec

> Generated from `contracts/component_boundaries.json`. Do not edit this file directly.

**Component ID:** `writer_tauri_app_service`  
**Status:** `active_w2_a2`

## Role

- Own the Tutorial Writer runtime orchestration boundary: transient GEL read session use, read-only archive navigation, one explicit governed A2 archive-sync trigger, one ephemeral Rust-owned tutorial draft, typed semantic edits and safe frontend view models.

## Scope

- Use D2 ArchiveRepository read-only models for class/student/tutorial navigation.
- Open New drafts only by composing latest authoritative archive source, N2b validated New form and N2c build_new_form_state.
- Open Revision drafts only from D2 revision authority plus fetched/validated historical edit form and C2 semantic construction.
- Own one ephemeral base/current draft container and serialize state-changing operations.
- Apply frontend edits only through rust_semantic_form::apply_tutorial_draft_edit candidate-before-commit semantics.
- Expose only an explicit Tauri command allowlist; no tutorial submit/create/revise/delete, generic HTTP, teacher reassignment or raw POST command exists. The sole local archive mutation trigger is ui1_sync_archive, which delegates to public RustArchiver and never exposes ArchiveSyncRepository.
- Project Writer student view models from D2 source fields: course start/end and attendance.
- Derive last-tutorial date/type only from the first item of D2 canonical newest-first tutorial history; do not synthesize it in React.
- Project recognized archive overall-level labels to compact canonical CEFR codes in safe UI view models while preserving authoritative source text unchanged.
- Project UI1c field-disposition rules and Rust-owned CEFR/assessment/InitialCourseType option domains in DraftView.formContract.
- Project InitialCourseType state without asking React to parse teacher_comments.
- Return DraftValidationIssue directly from ui1_apply_draft_edit; infrastructure failures are mapped to structured non-field issues.
- Project Aims assistance as unavailable while ui1c_aims_assistance is absent_not_curated.
- Resolve archive path with non-empty GEL_ARCHIVE_DB first; otherwise use gel-new-v2.db beside the running executable on Windows and project-root gel-new-v2.db on non-Windows. Navigation opens ArchiveRepository read-only; authenticated ui1_sync_archive may ask RustArchiver to atomically create a missing schema-v2 DB or synchronize an existing valid one.
- UI1c5 adds no Tauri command; integrated acceptance reuses the existing UI1c typed edit/draft surface.
- Expose Rust-owned Harper check/suggestion DTOs and dictionary add/remove/list commands without granting tutorial write authority.
- Intercept window CloseRequested events when the active draft is dirty, prompting for discard confirmation before window destruction.
- Transition writer_active_draft to stale_source upon session expiry or remote latest-tutorial drift; forbid silent rebinding to new source or teacher authority.
- Ensure all navigation actions (class selection, student change, New tutorial opening, Revision opening, logout) enforce discard guards when draft is dirty.
- Coordinate production tutorial submission via live_submission_transport, triggering post-submit readback and targeted archive reconciliation.

## Authority

- Application orchestration authority only; semantic field validity remains rust_semantic_form authority, archive history remains D2/Archiver authority, and GEL session transport remains rust_gel_session authority.
- May replace writer_active_draft only with fully validated semantic state returned by higher-authority components.
- May trigger canonical local archive synchronization only by delegated RustArchiver::sync_full; this does not grant direct SQLite/ArchiveSyncRepository capability or GEL tutorial mutation authority.
- Serialize Harper dictionary mutations through the existing writer_operation lock; the dictionary repository remains the sole durable dictionary writer.

## State transitions

- No draft -> New/Revision open -> clean writer_active_draft.
- Clean -> typed semantic edit -> validated candidate -> dirty; failed candidate leaves prior draft unchanged.
- Draft -> discard/logout -> no draft.
- Later UI1 gates may add explicit stale/invalid transitions but never silent source rebinding.
- Draft -> session expiry / remote latest-tutorial drift -> stale_source; direct editing locked; silent rebinding forbidden.
- Dirty draft -> window close requested -> intercepted -> discard confirmed -> no draft + window destroyed.
- Dirty draft -> window close requested -> stay -> remain dirty in-memory.

## Failure semantics

- Blocked/ambiguous D2 revision authority refuses Revision opening.
- Missing authentication refuses New/Revision live source acquisition without affecting archive navigation.
- Failed semantic edit returns an error and leaves current authoritative in-memory draft unchanged.
- Structured edit failures are returned without mutating writer_active_draft; React may render message/field metadata but cannot infer semantic authority from strings.
- A missing archive may be created only by authenticated explicit RustArchiver sync. Existing invalid/non-v2 archives fail closed and are never replaced or migrated in place by Writer.
- Archive synchronization failure leaves RustArchiver/ArchiveSyncRepository transactional failure semantics authoritative; Writer receives an error and does not fall back to raw SQLite or Python mutation.
- Session loss while writing transitions draft to stale_source; New drafts cannot rebind to an unauthenticated session.
- Window close attempt while dirty cannot silently drop in-memory draft without explicit discard confirmation.
