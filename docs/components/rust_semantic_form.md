# Rust semantic form model — active component spec

> Generated from `contracts/component_boundaries.json`. Do not edit this file directly.

**Component ID:** `rust_semantic_form`  
**Status:** `active_ui1c5`

## Role

- Construct and validate editable semantic tutorial state from governed source authority, including UI1c5-integrated field applicability, structured edit validation, Initial course-type storage adaptation, and New-only same-role CEFR regression protection.

## Scope

- Normalize CEFR, assessments, exam state, Aims and comments.
- Represent DraftOrigin explicitly as Revision { source, source_teacher_id } or New { optional prepopulation_source, opaque ValidatedNewFormTeacher }; New has no authoritative created GEL identity.
- Bind teacher attribution immutably to origin authority: historical teacher for Revision, validated fetched New-form teacher for New; expose no semantic teacher reassignment path.
- Keep one editable representation for each semantic value; raw overall-level text and Aims HTML are provenance-only.
- Use archive/summary authoritative absent while retaining edit discrepancy provenance.
- Represent Final Reading and enforce tutorial-type applicability invariants.
- Require explicit historical state authority before constructing a revision-by-ID draft.
- Treat an optional New prepopulation source as provenance only: when present it must be canonical and belong to the same student; first-ever New may have no source.
- Keep source authority distinct from editable derived state; source/session changes invalidate rather than silently reinterpret a draft.
- Construct New semantic state through the N2c field-by-field prepopulation contract: latest tutorial is carried source when present; validated New form supplies date/teacher/type and defaults for fields unavailable on the source type.
- Project New level fields only from the same canonical semantic role: Initial-role fields copy only from Initial/Final sources; current-role fields copy only from Standard/Final sources; unavailable roles retain validated New-form defaults; equal values never create provenance.
- Copy/reset type-specific state according to N2c: Standard-only self-assessment/Aims, Initial-only exam fields, Final-only additional comments; unavailable source-type fields fall back to validated New-form defaults.
- Own the executable UI1c tutorial semantic field-disposition matrix: editable, read-only, hidden-preserved or inapplicable by tutorial type.
- Project canonical CEFR, assessment and InitialCourseType option domains for safe Writer view models; React must not own those domains.
- Interpret Initial teacher_comments through the lossless InitialCourseType adapter: exact HSP/G21/G15 are recognized, blank is unset, every other nonblank value is preserved verbatim until explicit replacement.
- Reject direct Initial teacher-comment and hidden exam edits; hidden Initial storage survives unrelated edits unchanged.
- Return structured DraftValidationIssue values for typed edit failures with stable code/field/severity/message/prior/candidate fields.
- For New only, retain a same-role CEFR regression baseline derived from the N2c latest authoritative source snapshot and reject lower populated candidate levels with LEVEL_REGRESSION.
- UI1c5 integrated cross-form acceptance is executable through dedicated structural and behavioral checks without changing runtime authority.

## Authority

- Derived editable state only; archive/source evidence remains authoritative history.
- N2a origin authority is executable: Revision identity/teacher are immutable source authority; New has no created identity and its form teacher is immutable source authority.
- N2c is current authority for New draft prepopulation/default/reset semantics; GEL New-form values remain source/default evidence, not permission for cross-field inference.
- UI1c0 is current authority for Writer field applicability, option domains, InitialCourseType storage adaptation, structured draft validation and New-only same-role CEFR regression.

## State transitions

- Validated revision evidence creates a clean Revision semantic state bound to source identity and historical teacher.
- Validated New-form authority may create a New semantic state with the latest prepopulation source when one exists, or no prepopulation source for a first-ever tutorial; N2b owns the sole production New-form authority constructor.
- Semantic edits change only editable semantic fields and invalidate any derived POST payload.
- A changed latest prepopulation source, authentication loss, or changed Revision source marks the relevant draft stale; it is never silently rebound.
- Latest source + ValidatedNewTutorialForm -> New TutorialFormState only through N2c canonical field projection; first-ever New uses validated form defaults and has no source identity.
- Typed UI1c edit -> field-disposition authorization -> candidate mutation -> semantic invariant validation -> same-role New regression validation -> replace state only on success.

## Failure semantics

- Semantic revision construction only accepts a validated GEL edit form and historical state authority that permits revision-by-ID.
- Revision origin source identity must match student and tutorial type, and semantic teacher must equal source_teacher_id.
- New form teacher authority must be positive and semantic teacher must equal the opaque validated New-form teacher; an optional prepopulation source must be canonical and belong to the same student.
- New origin must never claim an authoritative created GEL identity before future fresh server readback.
- Type-inapplicable populated fields fail semantic validation rather than being silently discarded.
- Historical absent remains archive/summary-authoritative under ANOM-ABSENT-001.
- Ambiguous divergent, incomplete, unmatched or legacy ambiguous-unknown archive state blocks revision-by-ID before semantic state construction.
- N2c rejects a mismatched/non-canonical latest source and never copies across semantic dimensions or Initial/current roles; fields unavailable on the source tutorial type use validated New-form defaults rather than invented values.
- Read-only, hidden-preserved and inapplicable UI1c fields reject direct edits with FIELD_NOT_APPLICABLE.
- Invalid dates/options/text lengths and New same-role level regressions return structured DraftValidationIssue and leave the input state unchanged.
