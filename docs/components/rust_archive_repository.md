# Rust archive v2 read repository — active component spec

> Generated from `contracts/component_boundaries.json`. Do not edit this file directly.

**Component ID:** `rust_archive_repository`  
**Status:** `active_d2`

## Role

- Public read-only typed repository over an existing archive-schema-v2 database for Writer/Viewer navigation and fail-closed historical revision loading.

## Scope

- Open only existing schema-v2 SQLite databases in read-only/query-only mode.
- Expose typed class, membership, student and tutorial list models.
- Construct ArchivedTutorial only from source-present governed revision state.
- Reject missing/blocked collision authority, stale identity/state presence, wrong schema version and FK-invalid databases.

## Authority

- Read projection authority for archive schema v2.
- No authority to create, migrate, synchronize, invalidate or mutate archive history.

## State transitions

- SQLite rows -> typed read models only.
- Eligible governed identity/state -> ArchivedTutorial; blocked/stale authority -> explicit blocked result.

## Failure semantics

- Open fails unless PRAGMA user_version=2, migration metadata is present, required view exists and foreign_key_check is clean.
- Revision loading fails closed rather than synthesizing values from missing/ambiguous state.
