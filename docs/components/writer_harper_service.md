# Writer Harper service — active component spec

> Generated from `contracts/component_boundaries.json`. Do not edit this file directly.

**Component ID:** `writer_harper_service`  
**Status:** `active_ui1d`

## Role

- Rust-owned British-English Harper checking service for bounded Writer text fields.

## Scope

- Check only Aims, Teacher Comments and Final Additional Comments.
- Use harper-core 2.8.0 curated lint group with Dialect::British.
- Build Document and LintGroup from the same merged curated+user dictionary.
- Apply session-only disabled_rules and suppressed_kinds filters without mutating the dictionary.
- Short-circuit Spelling findings when the user dictionary matches or covers the reported span (handles mixed alphanumeric product names like CHI365/Chi365).
- Return DTOs containing messages, original text, span coordinates (char offsets, end-exclusive), stable rule names, suggestion labels and complete replacement suggestions; never mutate tutorial state.

## Authority

- Derived assistance only; rust_semantic_form remains authoritative for tutorial values and typed edits.
- No GEL/network/archive write authority.

## Reads

- `harper_user_dictionary`

## Writes

- `harper_check_result`

## Must not write

- `semantic_form_state`
- `writer_active_draft`

- `harper_ignored_findings`

## State transitions

- text snapshot -> HarperCheckDto -> discard on source change/request-id change
- disabled_rules/suppressed_kinds filter applied per check call without mutating dictionary

## Failure semantics

- Check failure becomes non-authoritative UI error; no draft mutation.
