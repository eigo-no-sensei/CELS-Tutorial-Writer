# Dependency lock tooling — active component spec

> Generated from `contracts/component_boundaries.json`. Do not edit this file directly.

**Component ID:** `dependency_lock_tooling`  
**Status:** `active_gri`

## Role

- Own reproducible dependency-resolution decision state and its derived lock-identity projection.

## Scope

- Define one Rust workspace release graph rooted at Cargo.toml.
- Generate Cargo.lock and writer-ui/package-lock.json only through their real package managers after an explicit dependency/workspace change.
- Generate and validate governance/dependency-lock-manifest.json.
- Detect LOCK_GENERATOR_UNAVAILABLE automatically per missing lock; never accept a manual override, placeholder lock, network failure or command failure as that exception.

## Authority

- Sole repository writer of dependency_lock_state; package manifests remain reviewed source inputs.
- Lock generation is explicit and never occurs as an incidental release-gate side effect.
- A portable tool-unavailable exception can produce SKIP evidence only; it cannot create dependency identity or authorize strict/release promotion.

## State transitions

- Dependency manifest edit -> lock state stale -> explicit generate_dependency_lockfiles.py -> validated lock decision -> derived lock manifest current.
- Missing lock + corresponding generator absent -> portable LOCK_GENERATOR_UNAVAILABLE evidence -> dependency identity remains incomplete -> generator appears -> exception invalid -> lock generation required.

## Failure semantics

- Missing generator executable never fabricates lock bytes; portable lock validation reports explicit SKIP only for the affected missing lock(s).
- If a missing lock has an available generator executable, dependency-lock validation fails rather than using the exception.
- Network unavailability or package-manager command failure is not the tool-unavailable exception and fails generation.
- Strict validation always fails while any required lock is missing; STRICT_ACCEPTED and RELEASE_ARTIFACT_VERIFIED require complete dependency identity.
